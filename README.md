# When is the Gohberg–Krupnik lower bound for aI+bH sharp?

The paper: https://doi.org/10.5281/zenodo.23732817

What is in this repository:

- [lean/](lean/) - the Lean 4 proof of the paper's results. Click it to see the proof, what it takes as given, and how to check it.
- [interval/](interval/) - the interval calculations that verify the paper's numerical inequalities. Click it to see the programs and how to run them.
- [illustration/](illustration/) - the program for the two values the paper labels as computed numerically. Click it to see the program and its output.
